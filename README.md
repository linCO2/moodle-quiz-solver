# moodle-quiz-solver

天下苦水课久矣——网课尤甚！今有神助众学生于水火之中：

**Moodle 通用答题助手** —— 一次确认，全自动答完所有题；交卷永远留给你点。

> 这是一个 Tampermonkey userscript，适用于**任何 Moodle 站点**（不限学校、不限课程）。

---

## 它做什么

| 时机 | 谁做 |
|---|---|
| **开始** | **你**点一次面板上的「🚀 放任自流」 |
| 中间 | **脚本**：抓本页题 → 问大模型 → 自动填入 → 自动点「下一页」→ 页面刷新后自动接着干 |
| **结束** | 到达提交页**停下**、高亮「提交所有答案并结束」，**由你点**。**绝不自动交卷。** |

支持题型：单选、多选、判断、填空、数值、论述、匹配。
其它题型（拖拽、完形填空等）**不猜答案**，标红交给你。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，把 `moodle-quiz-solver.user.js` 内容粘进去，Ctrl+S
3. 打开任意 Moodle 测验的作答页（`/mod/quiz/attempt.php?...`）

## 使用

面板上填：接口地址（OpenAI 兼容，含 `/v1`）、API Key、模型名。
然后点「🚀 放任自流」。

安全阀：
- 单次最多 **40 页** / **60 批模型请求**，超了自动停机（防死循环烧钱）
- 出现「会话超时 / 不允许再次作答 / 测验已关闭」→ **立刻停机**，不硬闯
- 翻页没生效导致回到已答过的页 → **停机**，绝不重复作答
- 面板顶部随时显示 **已处理 N 页 / 已请求 M 批**


## 边界

- **不自动交卷。** 交卷不可逆、有次数限制，这一步永远留给人。
- 不猜答案。模型返回空就标红，不填假答案。
- 只操作当前页表单，不发额外请求去构造答案。
- API Key 存在浏览器本地（`GM_setValue` / `localStorage`），脚本不内置任何 key。
